## Invent a Word We Need

One invented word and one clear line, 97 characters: "Appnesia" — a blend of app and amnesia — picking up your phone for a reason, then forgetting it the moment the screen lights up. A real gap every reader recognises, a word English could plausibly have grown.

`main.py` writes the exact line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
